# D&D 5e (2014) — Полная редакция на русском языке

## Модуль для Foundry VTT 13.351

Полная редакция Dungeons & Dragons 5-й редакции (2014) на русском языке для виртуального стола Foundry VTT.

## 📋 Описание

Модуль предоставляет полную локализацию и данные для D&D 5e (редакция 2014 года) на русском языке. Включает лист персонажа, компендиумы с расами, классами, предметами, заклинаниями и способностями.

## 🎯 Совместимость

- **Foundry VTT**: 13.351+
- **Система dnd5e**: 4.0.0+
- **Язык**: Русский

## 📦 Установка

### Способ 1: Через манифест (рекомендуется)

1. Откройте Foundry VTT
2. Перейдите в **Настройки** → **Управление модулями**
3. Нажмите **Установить модуль**
4. Вставьте URL манифеста:
   ```
   https://github.com/dnd5e-ru/foundry-dnd5e-2014/releases/latest/download/module.json
   ```
5. Нажмите **Установить**
6. Активируйте модуль в списке модулей вашего мира

### Способ 2: Ручная установка

1. Скачайте ZIP-архив модуля
2. Распакуйте содержимое в папку `Data/modules/dnd5e-2014-ru/`
3. Перезапустите Foundry VTT
4. Активируйте модуль в настройках мира

### Способ 3: Через веб-интерфейс

Используйте кнопку "Скачать модуль" на странице этого приложения для получения ZIP-архива.
