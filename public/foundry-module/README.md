# D&D 5e (2014) — Полная редакция на русском языке

![D&D 5e](https://img.shields.io/badge/D%26D_5e-2014-red)

Полная редакция Dungeons & Dragons 5-й редакции (2014) на русском языке для виртуального стола Foundry VTT.

## 📋 Описание

Модуль предоставляет полную локализацию и данные для D&D 5e (редакция 2014 года) на русском языке. Включает компендиумы с расами, классами, предметами, заклинаниями, способностями и предысториями.

| **Редакция** | D&D 5e (2014) |

## 📦 Установка

### Способ 1: Через манифест (рекомендуется)

1. Откройте Foundry VTT
2. Перейдите в **Настройки** → **Управление модулями**
3. Нажмите **Установить модуль**
4. Вставьте URL манифеста:
   ```
   https://github.com/dnd5e-ru/foundry-dnd5e-2014/releases/latest/download/module.json
   ```
5. Нажмите **Установить**
6. Активируйте модуль в настройках вашего мира

### Способ 2: Ручная установка

1. Скачайте ZIP-архив из [Releases](https://github.com/dnd5e-ru/foundry-dnd5e-2014/releases)
2. Распакуйте содержимое в `Data/modules/dnd5e-2014-ru/`
3. Перезапустите Foundry VTT
4. Активируйте модуль в настройках мира

## 📚 Содержимое

### Компендиумы (7 шт.)

| Компендиум | Тип | Содержимое |
|-----------|-----|-----------|
| 🧬 Расы (RU) | Item | 9 рас с подрасами |
| ⚔️ Классы (RU) | Item | 12 классов с таблицами уровней |
| 🎒 Предметы (RU) | Item | Оружие, доспехи, снаряжение, зелья |
| ✨ Заклинания (RU) | Item | Заговоры и заклинания 1-5 кругов |
| ⭐ Способности (RU) | Item | Расовые и классовые черты |
| 📜 Предыстории (RU) | Item | 13 предысторий |
| 📖 Правила (RU) | Journal | Основные правила на русском |

### Расы (9 + подрасы)
- Человек
- Эльф (Высший, Лесной, Дроу)
- Дварф (Горный, Холмовой)
- Полурослик (Легконогий, Крепкий)
- Драконорождённый
- Гном (Лесной, Скальный)
- Полуэльф
- Полуорк
- Тифлинг

### Классы (12)
Варвар, Бард, Жрец, Друид, Воин, Монах, Паладин, Следопыт, Плут, Чародей, Колдун, Волшебник

### Предметы (23+)
- Оружие: Кинжал, Длинный меч, Двуручный меч, Секира, Рапира, Длинный лук
- Доспехи: Кожаный, Клёпаный кожаный, Кираса, Полулаты, Кольчужный, Латы
- Снаряжение: Рюкзак, Верёвка, Факел, Сухой паёк, Набор целителя, Воровские инструменты
- Зелья: Лечение, Старшего лечения, Высшего лечения

### Заклинания (25+)
- Заговоры: Огненный снаряд, Свет, Волшебная рука, Потусторонний разряд, Руководство
- 1-й круг: Волшебная стрела, Щит, Лечащее слово, Лечение ран, Обнаружение магии, Благословение
- 2-й круг: Туманный шаг, Невидимость, Духовное оружие
- 3-й круг: Огненный шар, Контрзаклинание, Полёт, Ускорение, Рассеивание магии, Молния, Воскрешение
- 4-й круг: Врата измерений, Полиморф
- 5-й круг: Оживление, Конус холода
